This page is the product. A homepage still has a lockfile, a content-security policy, and a guestbook that disappears if the lights in the back are off.

How it's made

  • Azure Static Web AppsStatic HTML on the edge. GitHub Actions deploys main.
  • Content-Security-PolicyNo inline handlers. Hashes for the few inline scripts. jsDelivr only for Three.js and Web Vitals.
  • Guestbook + hit counterAzure Functions + Table Storage. If the backend is missing, they vanish. No fake numbers.
  • Rybbit AnalyticsSelf-hosted. Web Vitals reported as custom events.
  • Doto + original glyphsSelf-hosted type. Icons are currentColor SVGs in icons.js, not an icon font.
  • GeoCities modeThe cone, Konami, or typing clippy. MIDI is a square-wave sting, not an alert().
  • Playwright + Lighthouse CISix viewports, guestbook races, CSP hash check, search index freshness.
  • GitHub as CMSProjects and “currently building” come from the public API. Thoughts are HTML on purpose.
