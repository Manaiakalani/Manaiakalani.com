How it's made

  • Azure Static Web AppsStatic HTML on the edge. GitHub Actions deploys main.
  • Content-Security-PolicyNo inline handlers. Hashes for the few inline scripts. jsDelivr only for Three.js and Web Vitals.
  • Guestbook + hit counterAzure Functions in front of Cloud Firestore. Live as backend: unconfigured until a Firebase service account is set — scripts/enable-firebase-guestbook.sh. No fake numbers.
  • Rybbit AnalyticsSelf-hosted. Web Vitals reported as custom events.
  • Doto + original glyphsSelf-hosted type. Icons are currentColor SVGs in icons.js, not an icon font.
  • GeoCities modeThe globe, Konami, or typing clippy. MIDI is a square-wave sting, not an alert(). Minesweeper lives in 1997.
  • Playwright + Lighthouse CISix viewports, guestbook races, CSP hash check, search index freshness.
  • GitHub as CMSProjects and “currently building” come from a same-origin /api/repos proxy, falling back to GitHub. Thoughts are HTML on purpose. Source.
